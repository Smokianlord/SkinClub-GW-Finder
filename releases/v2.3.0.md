# SkinClub GW Finder v2.3.0

## New: Quizzes tab
- Lists every SkinClub community quiz with its link, 1st-place prize, number of participants and end date.
- Live quizzes come first, the one ending soonest on top; closed quizzes follow.
- Click a link to open the quiz, or copy it with one click. Sorting and search work as in the other tabs.
- The list is kept up to date by Refresh, Deep Search and the automatic checks.

## Changes
- The **Active** tab is now called **Creator**.
- Fixed: some giveaways were saved without their promocode and minimum deposit, because their entry code carried a different date than their link. These are now read correctly.

## Install
Download `SkinClub-GW-Finder-v2.3.0-Windows.zip`, extract it, close any older copy (use **Exit** in the tray menu) and run `SkinClubGWFinder.exe`. Your saved giveaways and settings carry over. Requires Windows 10 or 11.
