## What's new

- **Browser cleanup and lower resource use:** renders one page at a time, with a hard limit of five app-owned browser processes including children. The complete process group closes after each page, even if its parent exits first. Added timeouts, a cleanup watchdog, and temporary-profile cleanup retries.
- **Live Logs tab:** source requests, page checks, queued renders, browser counts, results, errors, and cleanup confirmations. Includes Copy/Clear and the latest 2,000 session events.
- **UI improvements:** dedicated Active, Joined, and History tabs with counts; rounded controls; clearer table headers; dark search; improved smaller-window layout and empty states.
- **Smoother filtering:** debounced search, shared fonts, and preserved row selection.
- **Reliability fixes:** atomic saves with backups, preservation of unreadable data, invalid saved-entry handling, correct redirect handling, and prevention of accidental right-click actions.

## History retention change

History now keeps **the 30 most recent giveaways**, replacing the one-month rule. Older History entries are automatically removed on load and save. **Joined giveaways are preserved.** Back up `%LOCALAPPDATA%\SkinClub GW Finder\data.json` before upgrading if you need the complete old History list.

## Download and run

1. Download **SkinClub-GW-Finder-v1.3.0-Windows.zip** and extract it.
2. Close older copies of the app.
3. Run **SkinClubGWFinder.exe**. Existing saved data loads automatically.

Requires Windows 10/11, .NET Framework 4.8, internet, and Edge or Chrome for rendered-page metadata. No installer is required. This build is unsigned.
