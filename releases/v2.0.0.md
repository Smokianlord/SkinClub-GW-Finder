# SkinClub GW Finder v2.0.0

## New look
- A completely new design: dark purple background with pink and blue glows and faint gifts, coins, cash, gems and knives behind everything.
- A stats strip at the top: active giveaways and tickets left, giveaways ending within 48 hours, joined giveaways, and the cheapest entry.
- A clearer table: creator tiles, ticket bars, promocode chips, deposits with a coin, and "in N days" under each deadline. Names, links and codes are always shown in full.
- New app icon and sharper text.
- Smoother resizing and maximising.

## Finds more giveaways
- Pages in any language are read correctly: Spanish, Portuguese, Turkish, Arabic and more.
- 15 more creators are built in, and any creator you add a link for is searched automatically from then on.
- A Deep Search runs by itself every 60 minutes, so new giveaways turn up without pressing anything. Starting the app only does the quick re-check.

## Easier to use
- **Refresh** is now a quick check of tickets, deadlines and ended giveaways, done in seconds.
- **Add links** accepts many links at once, one per line.
- Minimum deposits are always shown in USD, for example `5$`.
- Simpler Settings: the browser is chosen automatically.

## Install
Download `SkinClub-GW-Finder-v2.0.0-Windows.zip`, extract it, close any older copy and run `SkinClubGWFinder.exe`. Your saved giveaways and settings carry over. Requires Windows 10 or 11.
