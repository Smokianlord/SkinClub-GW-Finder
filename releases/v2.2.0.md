# SkinClub GW Finder v2.2.0

## Runs in the tray
- Closing the window keeps the app running in the system tray, still checking for new giveaways in the background.
- Left-click the tray icon to open the window. Right-click it for **Deep Search**, **Refresh**, **Joined giveaways** or **Exit**.
- A Deep Search or Refresh started from the tray shows its result in a small pop-up, for example "2 new: Pinkdrive, TACO. 28 active."
- **Exit** in the tray menu closes the app completely.

## Sharper icon
- The app icon is shown crisply in the title bar, taskbar, Alt+Tab and tray.
- Fixed: the taskbar could keep showing the old app icon after updating.

## Install
Download `SkinClub-GW-Finder-v2.2.0-Windows.zip`, extract it, close any older copy (use **Exit** in the tray menu) and run `SkinClubGWFinder.exe`. Your saved giveaways and settings carry over. Requires Windows 10 or 11.
