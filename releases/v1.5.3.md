# SkinClub GW Finder v1.5.3

## Fixed

- **Deadlines now follow the live timer.** Once a giveaway's deadline was saved, the app never read the timer again, so a giveaway that the organizers extended kept its old date. The timer is now read again:
  - every time you press **Refresh** or **Deep Search**, and
  - on automatic refreshes when the saved deadline is older than 30 minutes (`DeadlineRecheckMinutes` in `settings.json`).
- Automatic re-checks use at most two browsers at a time, so they stay light on memory. A Refresh or Deep Search you start yourself uses all of them.

Unsigned Windows build. Requires .NET Framework 4.8 and Edge or Chrome for rendered-page metadata. Close the app before replacing the exe; on first start it re-reads the timers and corrects any stale deadlines.
