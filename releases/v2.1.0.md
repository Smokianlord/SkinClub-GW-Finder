# SkinClub GW Finder v2.1.0

## New: Prize Pool column
- Every giveaway now shows its total prize pool in USD, for example `1,000$`, with a trophy icon.
- Read from the giveaway page in any language: English, Spanish, Portuguese, Turkish, Arabic and more.
- Sort by prize pool to see the biggest giveaways first, or search for an amount.
- Giveaways you saved earlier, including ended ones in History, get their prize pool filled in on the next Refresh.

## Also
- The window is a little wider by default so every column, creator name, link and code stays fully visible.

## Install
Download `SkinClub-GW-Finder-v2.1.0-Windows.zip`, extract it, close any older copy and run `SkinClubGWFinder.exe`. Your saved giveaways and settings carry over. Requires Windows 10 or 11.
