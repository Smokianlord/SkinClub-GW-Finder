# SkinClub GW Finder v1.5.2

## Changed

- **History shows the most recently ended giveaway first.** The sort arrow is on the Deadline column; click that header to reverse the order (oldest first).
- Each tab (Active, Joined, History) now remembers its own sort, so changing the sort in one tab no longer affects the others.

The app records when it first noticed a giveaway had ended, and History is ordered by that. Giveaways that were already ended when first found use the day they were added.

Unsigned Windows build. Requires .NET Framework 4.8 and Edge or Chrome for rendered-page metadata. Close the app before replacing the exe.
