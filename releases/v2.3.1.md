# SkinClub GW Finder v2.3.1

## Fixed: Quizzes order
- Closed quizzes were listed alphabetically, so a quiz that had just ended could show up anywhere in the list.
- The Quizzes tab now lists live quizzes first (the one ending soonest on top), then closed quizzes from the most recently ended to the oldest. The order stays the same after every refresh.
- Closed quizzes show the date they ended, with "ended today", "ended yesterday" or "N days ago" underneath.

## Install
Download `SkinClub-GW-Finder-v2.3.1-Windows.zip`, extract it, close any older copy (use **Exit** in the tray menu) and run `SkinClubGWFinder.exe`. Your saved giveaways and settings carry over. Requires Windows 10 or 11.
