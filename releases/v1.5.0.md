# SkinClub GW Finder v1.5.0

## Highlights

- **History fixed:** it now shows each creator's latest giveaway, with the correct entry promocode. Ended pages only show an unrelated code, so saved codes and deposits are no longer overwritten, and damaged entries are repaired on load.
- **Never miss a giveaway:** failed or timed-out page checks are retried, requests per site are capped, unreachable pages are re-checked and reported in the status bar, and Deep Search no longer looks "complete" when something could not be read.
- **Much faster Deep Search:** about 15 seconds instead of about 5 minutes with the same results (up to 6 pages load at once, with a 4 GB browser memory budget and Windows-enforced process limits).
- **More creators:** iNoToRiOuS, TCK10, Karrigan and Theasylum added to the search list; `ExtraCreators` in `settings.json` adds more without recompiling.
- **Settings dialog and `settings.json`:** refresh interval, History size, latest-only History, notifications, browser, timeouts and limits.
- **Notifications:** optional Windows tray notice for new giveaways and giveaways ending today.
- **Logs tab:** live page-check progress next to browser processes, updated twice a second.
- **Reliability:** only one copy can run, crashes are written to `crash.log`, and silent errors now appear in the Logs tab.
- **Project:** the source is split into `src/`, `scripts/build.ps1` is the single build entry point, and CI runs the UI and browser tests.

Unsigned Windows build. Requires .NET Framework 4.8 and Edge or Chrome for rendered-page metadata. Back up `%LOCALAPPDATA%\SkinClub GW Finder\data.json` before upgrading; the first launch repairs damaged entry codes and keeps a copy as `data.json.before-code-repair`.
