# SkinClub GW Finder v1.5.1

A fix release for v1.5.0.

## Fixed

- **Ended giveaways reopening:** Portuguese pages show "FIM" for "ended" and the app did not know the word, so a refresh reopened ended giveaways (for example TCK10). "FIM" and the "ended" word in several other languages are recognised, and an ended giveaway is only reopened by a real future deadline.
- **Lost clicks:** a Join click or an added link made while a scan was running was overwritten when the scan finished. Scan results are now merged into your live data.
- **Settings dialog:** the note under "Open settings.json" overlapped the buttons.
- **Typed links:** the Add link box now accepts exactly one giveaway link, and only web links are ever opened.

## Improved

- **Logs tab** shows what the scan is doing: phase, sources read, page progress and running browsers, instead of a bare process count.
- **Faster and lighter:** one DevTools connection per browser page instead of about 40, the heavy whole-page scan only runs while a promocode or deposit is missing, Deep Search skips giveaways already saved as ended, and the buttons are usable straight after a scan.
- TLS 1.3 is allowed where Windows supports it.

Unsigned Windows build. Requires .NET Framework 4.8 and Edge or Chrome for rendered-page metadata. Close the app before replacing the exe, then press Refresh once so any wrongly reopened giveaway is corrected.
