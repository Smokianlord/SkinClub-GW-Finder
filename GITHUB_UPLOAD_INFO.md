## First release

**Tag**

**Release title**

`SkinClub GW Finder v1.0.0`

**Release description**

First public release of SkinClub GW Finder, a Windows desktop tracker for direct SkinClub creator giveaways.

Highlights:
- Deep Search across YouTube, Telegram, web search and known creator domains.
- Direct giveaway-page validation.
- Active, Joined and History organization.
- Joined giveaways are hidden from Active/History until removed.
- Ticket and deadline parsing with proper numeric/date sorting.
- Creator and field-specific search filters.
- Automatic refresh and local persistence.
- Polished Windows desktop UI with view-specific accents and dimensional controls.
