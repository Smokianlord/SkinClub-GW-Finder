# Contributing

Thanks for your interest in improving SkinClub GW Finder.

## Bug reports

Please include:

- Windows version
- What you expected to happen
- What actually happened
- Steps to reproduce the issue
- A screenshot when the problem is visual
- A giveaway URL when the issue involves parsing/validation

Do not post private account information, credentials, or unrelated personal data.

## Feature requests

Describe the workflow you want to improve and why it would be useful. If the feature changes Active, Joined, or History behavior, explain the expected movement between views.

## Pull requests

Keep changes focused. Avoid unrelated UI or parser rewrites in the same pull request unless they are required for the fix.

Before submitting:

1. Build and launch the app on Windows.
2. Check Active, Joined, and History behavior.
3. Test sorting and search/filtering.
4. Test Refresh and Deep Search when your change touches discovery or parsing.
5. Confirm existing local data still loads correctly.
